# 兼容与适用范围

[English](compatibility.en.md)

这页只回答一个问题：**我现在能不能用这个项目？**

最后核对：2026-09-25。

## 当前支持情况

| 项目 | 当前状态 |
| --- | --- |
| Windows | 当前开发和测试目标 |
| macOS | 还没有验证 |
| The Sims 4 1.127.41.1030 | 当前测试版本 |
| 其他 Sims 4 版本 | 还没有验证 |
| 不安装 Sims 4 的本地演示 | 可以使用 |
| 真实游戏 TS4Script | 可以构建，但还没有完成真机测试 |

## 哪些人现在可以用？

### 我只想下载一个完整 Mod 直接玩

**现在还不行。**

当前游戏脚本还在等第一次真实游戏验证。

### 我想先看看这个项目，不安装《The Sims 4》

**可以。**

本地演示不需要游戏，也不需要 API Key。

### 我已经有自己的 AI 伴侣或聊天服务

**目前需要开发者协助接入。**

项目已经有 AI 后端接口，但还没有面向普通用户的设置页面，不能直接填服务地址或 API Key 就使用。

### 我用 OpenAI 兼容 API、Ollama 或其他常见 AI 服务

**目前没有内置的一键接入。**

开发者可以写连接代码，但现在不能把这些服务宣传成“开箱即用”。

### 我想让 AI 控制 Sim

**当前版本不支持。**

现在只读取游戏状态。

### 我想参与开发或自己接入 AI

**可以。**

开发者可以使用本地演示、Python SDK、后端接口、协议文件、自动测试和 TS4Script 构建流程。

## 当前明确还没有的功能

- AI 自动控制 Sim；
- 自主游戏；
- AI 主动发消息；
- 主聊天和游戏聊天自动共享记忆；
- 远程 AI 服务设置页面；
- 一键安装器；
- 已验证的 macOS 支持；
- “所有 Sims 4 新版本都兼容”的承诺。

## 我们怎么写兼容性

不会写“支持最新版”，因为《The Sims 4》会持续更新。

以后只写：

```text
已验证：The Sims 4 <精确版本>
```

自动测试和真实游戏测试分开记录。

只有脚本真的在目标游戏版本中加载并正常工作后，才会写“已通过真实游戏测试”。
